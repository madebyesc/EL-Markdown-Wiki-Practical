# Frequently Asked Questions (FAQ)

## 1. What is GitHub Pages?

GitHub Pages is a service used to host static websites directly from a GitHub repository.

## 2. Is GitHub Pages free?[

Yes, GitHub Pages is available for free with public repositories.

## 3. Which files are supported?

GitHub Pages supports HTML, CSS, JavaScript and Markdown-based documentation.

## 4. How do I publish my website?

Go to Settings -> Pages, select the main branch and /docs folder, then click Save.

## 5. Can I update my website?

Yes. Changes pushed to the repository can update the published website.
